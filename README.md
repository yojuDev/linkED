# 🔗 LinkED

## 📌 Overview
LinkED is a web platform designed to connect students with alumni for mentorship, networking, and career opportunities.

The platform helps students gain real-world insights while enabling alumni to guide, mentor, and share opportunities with the next generation.

---

## 🚀 Features

- 👥 Student–Alumni Networking
- 🎯 Smart Matching System (skills & interests)
- 💬 Real-time Messaging
- 🧑‍🏫 Mentorship Request System
- 📄 Detailed User Profiles
- 📢 Job & Internship Sharing
- 🔍 Advanced Search & Filters

---

## 🛠️ Tech Stack

**Frontend:**
- HTML, CSS, JavaScript / React

**Backend:**
- Node.js / Express

**Database:**
- MongoDB

**Authentication:**
- JWT / OAuth
